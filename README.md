# TeamSalesTracker

A polished iPhone sales tracker app built in SwiftUI for team performance monitoring, pipeline tracking, deal entry, and daily sales activity.

## Run on your iPhone

1. Open the project in Xcode on a Mac.
2. Connect your iPhone to the Mac.
3. Select your device as the run destination.
4. Sign in with your Apple ID in Xcode.
5. Press Run.
6. After installation, the app icon will appear on your iPhone Home Screen.

## Home screen readiness

This version includes:
- app launch screen support
- app icon asset catalog
- clean iPhone-ready app layout
- local persistence for saved sales data

## Notes

You can install the app on your iPhone only from Xcode using your Apple Developer signing setup. GitHub alone cannot push an iPhone app directly to a device.
